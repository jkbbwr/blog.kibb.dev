This site is a personal space for technical notes, software projects, and experiments. 

### Writing & Content

All blog posts, opinions, and analyses are written and directed by me. While I frequently use AI assistants (like Claude, Gemini, ChatGPT, and Copilot) as sounding boards, research accelerators, rubber ducks, or for proofreading, the ideas, core arguments, and final prose are my own.

No posts are blindly generated or published unreviewed by AI.

### Code & Engineering

Code snippets and projects discussed here often involve AI-assisted workflows — pair programming with LLMs, generating boilerplate, exploring API designs, or diagnosing tricky bugs. Any code shared has been tested, understood, and run by me before posting.

### Images & Media

If AI-generated imagery or diagrams are ever used, they will be noted accordingly.
